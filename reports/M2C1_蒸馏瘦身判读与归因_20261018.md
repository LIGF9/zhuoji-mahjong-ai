## 2. 机制诊断：三个配方缺陷，不是容量

### 2.1 熵控制器把 H* 标定成「随机策略的熵」，全程对抗收敛（主因）

```
[coef] 熵基线 H0=2.057（段首 25 轮） → H*=1.954
```

冷启动时策略接近随机，前 25 轮的熵 2.057 被当成基线 → H* = 0.95×2.057 = **1.954**，
几乎等于随机策略自身的熵。于是策略一学习（熵降到 1.72），控制器就判定「熵太低」，
`ent_coef` 从 0.010 一路乘 1.6 顶到 **clamp 上限 0.500**：

| iter | H | ec | β |
|---|---|---|---|
| 1 | 2.080 | 0.010 | 0.800 |
| 60 | 1.723 | **0.500** | 0.682 |
| 120 | 1.715 | **0.500** | 0.562 |
| 240 | 1.812 | **0.500** | 0.322 |
| 300 | 1.918 | **0.500** | 0.202 |
| 420 | 1.968 | 0.220 | 0.000 |
| 600 | 1.945 | 0.263 | 0.000 |

**前 300 轮熵奖励一直在把策略往回推**（1.72 → 1.92），这正是 R11 的又一次实证：
熵不是强度代理，把它当被控量，在冷启动这种「熵本来就要大幅下降」的场景里是有害的。

### 2.2 β 在 400 轮撤净，而学生从第 120 轮起就不再像教师了

KLT 损失轨迹（越小越像教师）：

```
it40 0.478 → it120 0.390（最低）→ it200 0.418 → it280 0.501 → it360 0.643 → it400 0.729
```

**从 it120 起 KL 单调上升**。原因：β 线性退火，约束越来越弱，策略被稀疏奖励的 RL 拉走。
所谓「密蒸馏 + 强教师」实际上只在头 120 轮真正生效，后面 480 轮学生基本在裸跑自博弈 ——
而 10M 的自博弈在 M2 的 17 段里已经证明是零增益，4M 更不可能自己变强。

### 2.3 lr 衰减到下限，后 200 轮几乎不学

`lr 1.2e-5 → 4e-6`，it400 后就贴着 `--lr-min 4e-6`。配合 β=0 与高熵，后段既没有信号也没有步长。

### 2.4 佐证：段内 eval 轨迹与上述一致

```
it40 -7.94 → it120 -5.00 → it200 -3.45 → it280 -3.11 → it360 -2.82（最好）
→ it400 -4.35 → it480 -5.04 → it560 -7.37 → it600 -5.98
```

it360 是「蒸馏残余 + 自博弈」的平衡点，之后随 β 归零逐级走低。与 2400 副的 it0300 峰值一致。

## 3. 结论：P4 的容量问题**还没有被回答**

- 按预定判据，m2c1 判负，不能宣称「4M 容量不足」。三个混淆里任何一个都足以单独解释 3.0 的天花板。
- 可以确定的是：**「4M + 强蒸馏 + 高熵控制器 + β 撤净」这个组合打不过 10M**，差距 2.66（10.5σ）。
- 值得注意的正面信号：**it0060（60 轮）就到 0.825，it300 到 3.019** —— 冷启动 + 蒸馏的爬升速度本身不慢（10M 的 S 系爬同样的距离要 600+ 轮）。说明蒸馏通路是有效的，只是被后段配置拖垮。

## 4. 建议：m2c2 修正版（三处同时改，仍是一条路线的必要修复）

| 旋钮 | m2c1 | m2c2 | 理由 |
|---|---|---|---|
| 熵控制 | `H*=0.95·H₀`，H₀ 取冷启动前 25 轮 | **关闭控制器**：`--ent-coef 0`，或不给 `--ent-target-ratio` 让它自由下降 | 冷启动熵基线无意义；R11 已证熵不是强度代理 |
| β 退火 | 0.8 → 0 / 400 轮 | **0.8 → 0.2 / 600 轮**（保留弱蒸馏到段末） | KL 从 it120 起就反弹，说明 400 轮撤太快；弱蒸馏是学生的唯一稳定信号 |
| lr | 1.2e-5 → 4e-6 | **恒定 1.2e-5**（或 lr-min 8e-6） | 冷启动 600 轮远未收敛，后段不该衰减 |
| 其余 | — | 同 m2c1（m0 / 教师 d3_it0020 / anchor-warmup 100 / 192 局） | 单变量包 = 「让学习信号活到段末」 |
