## 1. 锁死定义（复述，不允许事后解释性修改）

- placement 向量按名次 1..4 = `[90.0, 45.0, 0.0, -135.0]`（计划 §3.4 给定，非项目既有口径），总和 0。
- 名次映射 `sorted(range(4), key=lambda i: (-deltas[i], i))`；同分按绝对座位号小者优先，确定性。
- 每行 `d_score = deltas[cand] − mean(其余)`、`d_place = place[rank(cand)] − mean(place[其余])`；`sgn ∈ {+1, −1, 0}`；一致 ⇔ 两者符号相同；一致率 = 一致行数 / 总行数。
- **预登记时即注明的数学关系**：`deltas` 严格零和 ⇒ `d_score = (4/3)·deltas[cand]`、`d_place = (4/3)·place[rank]`，故一致率度量的是「分差为正 ⟺ 名次前二」的吻合度；第 2 名负分、第 3 名正分都会记为不一致。这是设计使然，不是异常值处理。
- 主数据集 = `final_primary`；主结论同号检查 = `final_primary, combo2_main`（两个都要）；门禁阈值 = 一致率 ≥95% 且两数据集主结论同号。

## 5. 步骤③：训练奖励 / 教师 Q / 闸门 / 终评是否同一函数

| 层 | 文件 | 自动校验 | 口径说明 |
|---|---|---|---|
| 训练奖励（PPO rollout） | `train_ppo.py` | PASS | 终端奖励 = 四座净分差 deltas（零和）；势函数 Φ=8·Vθ 为 policy-invariant 塑形 |
| 奖励模块 | `zhuoji/reward.py` | PASS | 单步奖励 = 局终端分差增量 + γΦ(s') − Φ(s)；终局 Φ≡0，不改最优策略 |
| 教师 Q 采集 | `gen_exit.py` | PASS | 教师 n32-ply3 搜索输出全 28 槽 Q；Q 是动作条件下未来回报估计，不是终局分差 |
| ExIt 训练目标 | `train_exit.py` | PASS | L = CE(softmax(Q/τ)) + 0.5·SmoothL1(V, maxQ/8)；Q → 策略用 softmax、→价值用 /8 缩放 |
| 评估记录写出 | `eval_pairs.py` | PASS | 每条记录写四座 deltas 与候选座位；无动作轨迹、无逐决策字段 |
| 闸门 / 排名 / 终评统计 | `tools/final_eval_report.py` | PASS | 唯一冻结口径：d = v[cand] − mean(其余)，四座按 seed 平均，seed 维度正态近似 p |
| 闸门决策复用 | `tools/gate_decision.py` | PASS | 直接 import 冻结实现，无第二套统计 |
| best-of 排名复用 | `tools/bestof_rank.py` | PASS | 直接 import 冻结实现，无第二套统计 |
| E-POOL 多重比较 | `tools/pool_chunk.py` | PASS | 5 片 Holm step-down；本协议另给 BH-FDR 并列展示 |

**逐层结论（由代码事实直接推得，非统计推断）**：

1. **终评统计与闸门 / best-of 排名确实是同一函数**——三者都直接 import `final_eval_report.per_seed / stats`，不存在第二套口径；评估写出的 `deltas` 是零和分差。
2. **PPO 训练奖励与终评分差同源**：终端奖励就是 `result['deltas']`，势函数 Φ=8·Vθ 是 policy-invariant 塑形（ΣγᵗFₜ = −Φ(s₀)），不改变最优策略。⇒ 就「分差」这一 cardinal 目标而言，训练与评测**对齐**。
3. **教师 Q 不是终局分差本身**：ExIt 用教师搜索的全动作 Q 做 `softmax(Q/τ)` 策略目标与 `maxQ/8` 价值目标（VALUE_SCALE=8）。Q 是动作条件下的未来回报估计，经缩放后才进网络；价值头拟合得更好 ≠ 外部更强（TanyaoDojo oracle-critic 反例）。
4. **名次（ordinal）从未进入任何训练目标或评估口径**：placement 只在本审计中作为对照被构造出来。⇒ 若业务关心的是名次而非分差，`分差` 是**代理目标**，不是同一目标。

## 6. 步骤④：教师 Q 的未校准性（描述性，不建立相关性）

- 样本 `runs/exit_r01/exit_w0.npz`：`25000` 行 × `28` 槽；每行合法动作数 `2..14`（均值 `7.73`），非法槽为 NaN。
- 合法 Q 分位：min `-22.156` / p1 `-1.770` / p25 `-0.452` / 中位 `-0.153` / p75 `0.417` / p99 `11.266` / max `64.125`。
- 每行最优与次优 Q 差：中位 `0.2383`、p90 `3.4088`（有 ≥2 合法动作的行 `25000`）。
- **读法**：合法 Q 中位 `-0.153`、IQR `[-0.452, 0.417]`，但尾部跨 `-22.16..64.12`（p1/p99 = `-1.770/11.266`），长尾明显；每行最优与次优差的中位也很小 ⇒ Q 是**同一决策点内的相对动作分数**，跨状态不可比、未校准为胜率。
- 训练里价值头目标是 `maxQ/8`（`VALUE_SCALE=8`），说明 Q 与分差之间是**缩放映射**而非同一函数；非最优动作的 Q 尤其不可解释为胜率（Mortal FAQ 同类警告）。因此禁止把「Q 拟合更好 / maxQ 更大 / Q 熵更低」直接当作棋力提升，也禁止用它替代强度判定。

## 7. 门禁判读（机械执行 §6.72.2 I）

- 主数据集一致率 `61.70%` < `95%`。
- 两个主结论同号：`是`。
- **门禁结论：目标未对齐**（判据 = 一致率 ≥95% **且** 两数据集主结论同号，两者缺一不可）。

**这个数字的含义与不含义**（按预锁判据机械判读后的解释，不改变判定）：

- **含义**：按预锁的 placement 阶跃映射（第 1/2 名恒为正、第 3 名恒为 0、第 4 名恒为负），主数据集有 `766` / `2000` 行的逐局二值判定与分差符号不同 ⇒「优化分差」与「优化名次」**不是同一个二值目标**；按计划 §3.4 判据必须记未对齐。
- **不含义**：**不是**「模型有 38% 的局判断错了」、**不是**「训练代码有 bug」、**不是**「P48 对名次无效」。§5 的 9/9 代码溯源 PASS 已证明分差口径在训练 / 闸门 / 终评是同一函数；§3 显示聚合到 seed 层后两种口径的 Δ 方向一致 —— 分歧来自 ordinal 阶跃与 cardinal 连续量的**二值化方式差异**，主要落在第 3 名（place=0）与第 2 名负分。
- 因此门禁冻结的是「**以名次为目标的新 RL / 奖励塑形**」，不是冻结分差口径下的既有结论；v1.1 报告 §3/§4 与 §6.71.4 一字未改。
