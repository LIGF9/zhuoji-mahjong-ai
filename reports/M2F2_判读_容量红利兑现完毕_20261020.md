## 2. 落档判定：命中「|Δ| < 0.20 ⇒ 收敛」档

预登记判据（2026-10-20 11:16 起跑前写定，锚 4.983±0.236）：

| 档位 | 条件 | 是否命中 |
|---|---|---|
| 容量有剩 | it1200 ≥ 5.30 且 CI 下界 > 0 | ✗（5.163，差 0.137） |
| **收敛** | **\|Δ\| < 0.20** | **✓（+0.196）** |
| 过训回滚 | Δ < 0 | ✗ |

曲线形态：4.967 → 4.752（低谷）→ 5.106 → 5.149 → 5.163。**跌下去后收复并缓慢上行，但 540 轮只涨 0.196（每 60 轮 +0.02）**，且末段 klr 0.0003（教师信号利用率见底）、klt 从 0.089 反升到 0.105（越来越不像教师）。

## 3. 与 m2f1 合起来看：容量红利是一次性的

| 阶段 | 轮次 | 结果 | 增益 |
|---|---|---|---|
| m2f1（10M 冷启） | 600 | **4.983** | **对 4M 同轮 +0.490（显著）** |
| m2f2（续训） | +600 | 5.163 | 对起点 +0.196（不显著） |

**宽度红利集中在前 600 轮一次性兑现，之后同样进入平台。** 把「冷启 600 轮 + 续训 600 轮」合成一次对照：10M 用 1200 轮拿到 5.163，4M 用 1450 轮拿到 5.004——同轮次上 10M 略优，但**10M 单轮耗时是 4M 的 2.5–3 倍**（54 s vs 17–31 s）：

| 路径 | 累计墙钟 | 终点 |
|---|---|---|
| 4M：c2(600)+c3(850)+c4(850) | ≈16.5 h | **5.434** |
| 10M：f1(600)+f2(600) | ≈18.0 h | 5.163 |

**⇒ 10M 路线性价比为负，P4-C 关闭。** 容量确实是真实约束之一（f1 的 +0.49 无法用噪声解释），但它不是当前最紧的那道：多给的容量在 600 轮内就被吃完，剩下的差距不再由宽度决定。

## 4. 更关键的发现：学生的天花板 = 教师水平 − 0.16~0.39

把四段同池判读并排（每段的教师都是该段 KLT 的教师）：

| 段 | 教师（水平） | 学生末点 | 学生 − 教师 |
|---|---|---|---|
| m2c3 (`c3_it1260`) | d3_it0020（5.325） | 5.004 | −0.321 |
| m2c4 (`c4_it2280`) | master（5.680） | **5.434** | −0.246 |
| m2e1 (`e1_it2280`) | master（5.680，弱陪练） | 5.290 | −0.390 |
| m2f2 (`f2_it1200`) | d3_it0020（5.325，10M） | 5.163 | −0.162 |

**四段的落点全在教师下方 0.16–0.39，且与参数量无关**（9.84M 的 f2 落得离教师最近，4.07M 的 c4 绝对分最高）。这解释了为什么「加容量」「加轮数」「加强陪练」三条路都先后失效：

> **β = 0.2 的 KLT 项一直把策略钉在教师身后，学生的可及上限由教师决定，而不是由网络宽度或训练时长决定。**

这也与 m2e1 的归因自洽（教师是 m2c4 +0.386 的主因），并把「容量说」的适用范围收窄到一句准确的话：*容量买得到收敛速度，买不到上限高度。*

## 5. 下一步：唯一还没被试过的机制——解绑 KL 拉力

想把学生推过教师，只有一个方向：**在末段把 β 退火到 0**。这个实验此前跑过（m2c1），但结果是废的——当时 `master_model = teacher_model` 让 β→0 时**座位对手跟着教师一起静默消失**，后 200 轮实际是裸自博弈。该 bug 已在 2026-10-19 用 `--klt-teacher` 拆开修好，**现在可以干净地做这件事**。

建议 **m2g1**（R1 单旋钮，起点 = 当前全局最强）：

| 项 | 值 |
|---|---|
| init | `_ckpts/dushan_m2_c4_it2280`（**5.434±0.244**） |
| 段长 | 600 轮（编号 2281 → 2880） |
| 教师 | `--klt-teacher dushan_master`，β **0.2 保持 300 轮 → 300 轮线性退火到 0** |
| 座位对手 | `--master-ckpt dushan_master`（0.40，**β=0 后仍在**，这是关键差异） |
| 其余 | 4M（preset m0）/ 熵控关 / lr 恒 1.2e-5 / 与 c4 逐项相同 |

需要一次小改动：现有 `--klt-anneal-iters` 是「从第 0 轮就开始线性退火」，本实验要的是「先保持再退火」，需加 `--klt-hold-iters`（约 15 分钟，含探针）。判据：末点 − 5.434 **≥ +0.20 且 CI 下界 > 0** ⇒ 教师天花板被突破，这条路成立；**|Δ| < 0.20** ⇒ KL 拉力不是瓶颈，转 PPO 目标/采样侧（如更长的搜索或 value 重估）。
