## 1. 决策：为什么是 P3，为什么不是 P4

### 1.1 本项目的硬证据（全部受控实验）

| 实验 | 变量 | 结果 |
|---|---|---|
| m2p1 | 轮数 320 | +0.055 ± 0.223（零） |
| m2p2 | epochs 1→3 | **−0.310**（负） |
| m2p3 | games/iter 192→384 | −0.082（零） |
| m2d1/d2/d3 | 蒸馏 β 0.8/5.0/5.0+关控制器 | klt 0.645→0.197（−64%），level 只 +0.18（CI 内） |
| 三代对比 | 10M vs 769K | S11 = 5.680，10M 全程 ≤5.325 |

四条结论：
1. **优化器侧四旋钮全部排除** → 瓶颈在信号，不在优化。
2. **KL 距离不是强度的代理**（R11）→ "对齐 master 再自博弈"路线判死。
3. 分歧全在 discard（一致率 47.5%）、对 defensive 落后 43.4% → 缺口是**隐藏信息推断**。
4. 10M 在受控条件下能爬到 5.325（全程最高），**容量没到顶 → P4（缩模型）为时过早**。

### 1.2 前沿文献交叉验证

| 方法 | 出处 | 与本项目的关系 |
|---|---|---|
| **PTIE**（perfect-training, imperfect-execution） | PerfectDou, NeurIPS 2022：训练时喂完美信息目标、执行时只用可见信息 → **10× 样本效率** | 采集器天然持有全状态，标签零成本；正是"分歧全在 discard"短板的对症药 |
| **UNREAL 辅助头** | Jaderberg et al., ICLR 2017：共享主干 + 静止辅助目标，稀疏奖励下大幅加速 | 我们的 value 目标非平稳；辅助目标是**环境事实**（静止），对主干是稳定监督 |
| Suphx | AAIR 2020 | 论文原话 "simple knowledge distillation does not work" —— 印证 m2d 系判死；Suphx 的有效手段是 GRP（跨盘全局奖励，单局制不适用）与 Oracle Guiding（**用完美信息指导训练**——正是本轮做的事） |
| LuckyJ | Tencent, 2023 | 无人类数据自博弈 + 大规模对手池，验证纯自博弈上限取决于对手多样性（P2 留作下一步） |

### 1.3 结论

**P3 是当前唯一未测的机制性假设，且与全部已知证据相容；P4 推迟。**
落地形式不是泛泛的辅助头，而是 **PTIE 式完美信息辅助预测**：四个头全部只在训练时算标签，执行路径零改动。
