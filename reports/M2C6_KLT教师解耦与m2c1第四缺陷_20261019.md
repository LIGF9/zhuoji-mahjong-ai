# `--klt-teacher` 解耦改造 + 附带发现：m2c1 还有第四个缺陷（座位对手随 β 撤净一起消失）

> 2026-10-19 19:40 · 代码：`scripts/selfplay.py`、`zhuoji/vcollect.py`、`scripts/verify_snap_cache.py`、`scripts/_probe_klt_split.py`

## 1. 为什么要做

m2c4 起了 +0.386±0.246 这个 M2 唯一显著正增益，但**无法归因**：

```
--master-ckpt dushan_master   →  ① KLT 蒸馏教师（算 log π_teacher）
                              →  ② 一等对手座位（0.40 权重，命中时换 1~2 座）
```

换 master 同时改了"学谁"和"打谁"。要拆开，必须让这两条路径能指向不同模型。

## 4. 附带发现：m2c1 的第四个缺陷（代码级 bug）

改之前 `_worker` 里这一行：

```python
master_model = teacher_model if master_prob > 0 else None
```

座位对手**直接复用教师实例**。而 `teacher_ver` 在 β 退火到 0 时被置为 `None`（省掉 worker 侧前向），于是：

```
β > 0  →  teacher_ver 非空  →  座位对手 = 教师 ✅
β == 0 →  teacher_ver = None →  teacher_model = None → 座位对手 = None ❌ 静默消失
```

**m2c1 的配方正是 `β 0.8 → 0`（600 轮里前 400 轮退净）**，所以它从 it400 起同时失去了：
- KLT 蒸馏（已知，归因表里第二条）
- **0.40 权重的一等对手座位**（新发现，此前完全没登记）

即 m2c1 后 200 轮实际跑的是"纯自博弈 + 无强对手"，这解释了它为何在 320 轮后一泻到 2.239。m2c2–m2c5 都用了 `--klt-beta-end 0.2`，β 恒 > 0，所以没暴露；但**任何用 `--klt-beta-end 0` 的段都会踩**。

修复方式：`master_shared` 只在"教师本轮可用"时复用，否则回落到 `_MASTER_CACHE`；配合主进程 `need_own_master` 判断做全量重发兜底。

**结论修正**：m2c1 是「四缺陷」而非「三缺陷」。这不改变 m2c2 的结论（三处修正已被证实），但补上了 m2c1 曲线后段崩塌的完整解释。

## 5. 用这个开关怎么干净地拆 c4 的 +0.386

四格设计（每格 850 轮、其余配方与 c4 逐项相同、2400 副判读）：

| 格 | 教师 | 座位对手 | 回答什么 |
|---|---|---|---|
| 基线（= c4 重跑） | master | master | 复现 +0.386 |
| **A** | s5 或 d3_it0020 | master | 陪练变强值多少分 |
| **B** | master | 旧对手（c3_it1440 或快照池） | 教师变强值多少分 |
| C | 旧教师 | 旧对手 | 双弱基线 |

只需 **A、B 两格**就能把 +0.386 分解为「陪练贡献」与「教师贡献」（可加交互项）。每格 850 轮 ≈ 4.5 h + 判读 12 min。

> 建议先跑 B（教师仍是 master、只把陪练退回 c3）：因为教师项的梯度信号（klr）本段已很低，陪练项的嫌疑更大；且 B 格若显著为正，说明"对手池强度"这条线还能单独继续挖，与 10M 容量实验完全解耦。
