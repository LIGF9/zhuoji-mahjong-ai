# M2-B 塌陷诊断与配方修正（C8）

> 2026-10-15 14:35 · 依据：`reports/_early_ab_gap.json`、`_early_g2_400.json`、
> `m1_s4a_history.json`、`m1_s4b_history.json`、`_m1_s4b.out`（533 轮）

## 一句话结论

**M2-B 的 `s4b` 配方让模型变弱，不是变强** —— 第 500 轮时比 A 段末低 **2.18 ± 0.65（3.3σ）**，
已在第 533 轮**主动停止**（存档保留）。病因**不是"撤教师"**（A 段的最后 300 轮本身就是 β=0、
且涨了 +0.36），而是 **s4b 相对 A 段的三处退化：对手场变弱、master 出场变少、熵目标被压低**。

`score_checkpoints.py --deals 1000 --seed 31337 --anchor dushan_master`（6 workers，10.6 min）：

## 3. 病因：s4b 相对 A 段的三处退化

| 项 | A 段（成功：it300→it600 **+0.36**） | **s4b（塌陷）** |
|---|---|---|
| `--snapshot-pool` ★ | `dushan_master` | `dushan_m1_s3`（**更弱**） |
| `--master-seat-prob` | 0.30 | 0.20 |
| 熵目标 `H*` | **0.975**（H₀ = 1.026 实测） | **0.836**（H₀ = 0.880 实测） |
| `--lr-min` | 4e-6 | 3e-6 |
| ε 退火 | 已退到 0.01 | 从 0.03 **重新**退火 |

**★ `--snapshot-pool` 的语义容易被误解**：它不是"把当前模型的自身快照放进池子"，
而是**一批固定的常驻对手模型**（`selfplay.py:1170`：逐个 `torch.load` 成对手）。
所以 `--snapshot-pool dushan_m1_s3` = **把唯一的常驻对手槽位从"现任 master"换成了更弱的 M1-S3**。

**熵目标为什么漂移**：`H* = ratio × H₀`，而 `H₀` 是**本段段首 25 轮实测值**。
续训段的起点模型更尖 → H₀ 从 1.026 掉到 0.880 → 同一个 ratio=0.95 给出的绝对目标低了 0.14 nats。
B 段 `H` 长期在 0.72–0.80（低于 A 段的 0.96）⇒ 政策被推得更尖、探索更少。

**为什么可以排除"撤教师"**：A 段 β 在 300 轮内线性退到 0，**it300→it600 这 300 轮全是 β=0**，
期间 vs master 从 −1.413 涨到 −1.046。⇒ "没有教师就不行"与事实矛盾。

## 4. 修正配方（`s4b2`，已写入 `scripts/m1_launch_segment.py`）

**原则：回到 A 段已被证明有效的场，只保留 B 段"撤教师"这一个变量。**

| 项 | s4b2 取值 | 相对 s4b 的变化 |
|---|---|---|
| `--init` | `models/dushan_m2_a.pt` | 不变（A 段末） |
| `--iters` | **600** | 1200 → 600（先拿结论，可再延长） |
| `--klt-beta` | 0.0 | 不变（撤教师） |
| `--snapshot-pool` | **`dushan_master`** | ← 复位到 A 段 |
| `--master-seat-prob` | **0.30** | ← 复位到 A 段 |
| 熵目标 | **`--ent-baseline 1.026`** + ratio 0.95 ⇒ **H\*=0.975（绝对值钉死）** | ← 复位到 A 段 |
| `--lr-min` | **4e-6** | ← 复位到 A 段 |
| ε | **0.015 → 0.01（200 轮轻退火）** | 不再重开 3% 探索 |
| 其余（KL 锚/GAE/adv-norm/记忆等） | 与 A 段完全相同 | — |

> **`--ent-baseline` 是既有参数**（`selfplay.py:883`，>0 时跳过基线窗口、立刻开始控制），
> 所以"把熵目标钉成绝对值"**不需要改代码** —— 这也顺手补掉了 A1 环路在**续训段**的
> 一个系统性缺陷：`ratio × 本段实测 H₀` 在"上一段已经把熵降下来"之后会自动调低目标。

## 7. 从这次事故抽出的通用教训

1. **`ratio × 本段实测基线` 这类"相对"目标，在续训段会静默漂移** —— 只要上一段改变了被控量，
   目标就跟着变。跨段续训必须用**绝对目标**（或显式传入上一段的基线值）。
2. **对手场的强度是训练信号的一部分**：把常驻对手从强换到弱 = 换了目标函数，
   必须当成"配方变更"来审，不能当成"换个池子"的小事。
3. **门禁必须跑在训练进行中**（C7）：否则早警失效，塌陷只能事后知道 —— 这次靠人工体检才发现。
4. **内部评测只能看趋势、不能当判据**（段间漂移 ≈1.5 分）；跨段比较一律用同池配对判读。
