# M2C4（P4-A4）换教师：方案与预登记判据

- 日期：2026-10-19 08:40 配方 + 冒烟；**08:47 首起（600 轮）→ 08:53 中止并改 850 轮重起**
- 起点：`models/_ckpts/dushan_m2_c3_it1440.pt`（4.978，c3 末点）
- 唯一样本信号变化：KLT 教师 `d3_it0020`（5.325，v3/9.84M）→ **`dushan_master`（5.680，v1/64ch/0.77M）**

## 为什么换教师

| 证据 | 含义 |
|---|---|
| master 只有 **0.77M** 却打出 **5.680** | 容量明显不是约束；强策略是"学出来的"，不是"装出来的" |
| c3 的 klt 已降到 **0.114**、klr 0.0005 | 学生对 5.325 教师"能学的都学完了"——继续对着它蒸馏已无梯度可降 |
| 学生 5.004 停在教师 5.325 之下 0.32 | 差距只能来自"教师没教 / 学生没学会"，换更强的教师是最直接的检验 |
| 4M 与 master 参数量差 5× | 若 0.77M 能达到 5.68，4M 学生的天花板不应在 5.0 |

假设：**教师质量是当前瓶颈**。若学生换 master 教师后显著上移 ⇒ 继续"强教师蒸馏"路线（可再上 10M 或换更大教师）；若无变化 ⇒ 4M 在当前信号下确实到顶，与容量无关。

## 配方（R1：除教师外与 m2c3 逐位相同）

| 项 | 值 | 说明 |
|---|---|---|
| iters | **850**（编号 **1441→2290**） | `--iter-offset 1440` + history 追加。见下方「为什么从 600 改成 850」 |
| init | `c3_it1440`（4.978） | 用**末点**而非峰值 it1260（5.004）：峰值为选点最大值，带向上选择偏差（d3_it0020 的教训）；两点评分差 0.026 在 CI 内 |
| 教师 / 一等对手 | `dushan_master` | `--master-ckpt dushan_master` |
| β | 恒 0.2（start=end） | 同 c3 |
| 熵控制 | 关（ec 0.010） | 同 c3 |
| lr | 1.2e-5 恒定 + warmup 60 | ckpt 无 opt → 缓冲冷 Adam |
| KL 锚 | = init（warmup 0） | 同 c3 |
| 其余 | 192 局/轮、1 epoch、master 座位 0.40、save-every 60 | 逐位同 c3 |

**已知耦合（必须记录）**：`--master-ckpt` 一物两用——既当 KLT 教师，也当 0.40 座位的一等对手。换 master 会把**对手**同时从 5.325 提到 5.680。若结果为正，"教师更强"与"陪练更强"两个原因分不开；当前代码没有独立的 teacher 参数，拆解需另起一段（可加 `--klt-teacher`，约 1 小时改造 + 冒烟）。

**为什么从 600 改成 850（08:53 决定，改动时仅跑了 16 轮、无任何判读数据）**

实测换 v1 教师后 **16.9 s/轮**，比 c3 的 28.6 s/轮快 40%——因为教师从 9.84M 的 m1 换成 0.77M 的 master，教师前向几乎归零（collect 从 16 s 降到 5.9 s）。

而 c3 的曲线是**段内第 660 轮（it1260）才走平**的（前 60 轮 lr warmup 平坦，之后爬 +0.51，然后平台）。600 轮会在平台之前截断，使「训练量」成为与 c3 对比的混淆变量——那样得到一个 0 增益结果时无法区分"教师没帮助"和"轮数不够"。
⇒ 取 850 轮，**与 c3 轮数逐位对齐**；按 16.9 s/轮 ≈ 4.0 h，仍在午后出结果。

（首起 600 轮的那次在 it1456 中止，日志归档为 `reports/_m1_m2c4_aborted_600.out`，未产生 ckpt，history 空。）

## 预登记判据（2400 副 / vs c3_it1440 锚 = 4.978）

| **it2290** | 结论 | 下一步 |
|---|---|---|
| **≥ +0.25（≈5.23）且 CI 下界>0** | 教师质量是瓶颈，换教师有效 | 拉长段 800–1000 轮；或同配方上 10M |
| ±0.20 | 教师非瓶颈（学生已吸尽两位教师） | 4M 在当前信号下 ≈5.0 到顶；转数据/规则侧或收口 |
| ≤ −0.20 | v1 教师不适配 v3 学生（跨代策略语言不同） | 回退 d3 教师，改走"master 直接当学生"或 10M 重训 |

**过程观察项（不是判据）**：
- klt 起点：冒烟显示 0.34（换教师后必然跳高，因为分布不同）→ 是否在 200 轮内降到 <0.15
- H：master 策略更锐，若 H < 0.60 记多样性风险
- samples/轮：对手变强可能让对局变短；若中位 <7000 需查
