# 手机 / 平板访问（局域网）

> **2026-11-11 更新：地址变了。** 旧文档里的 `192.168.31.218:8770` 是上一台
> Windows 机器的地址，早已失效。当前机器（macOS）的地址是
> **`http://172.26.68.203:8770`**，本机自测用 `http://127.0.0.1:8770`。
> 换 Wi-Fi / 重连热点后地址会变，以服务启动时打印的那一行为准。

## 1. 启动

```bash
cd ~/zhuoji-mahjong-ai
.venv/bin/python web/dushan_server.py --port 8770 --threads 8
```

服务默认监听 `0.0.0.0`（所有网卡），同一 Wi-Fi 下的手机可直接访问。
启动日志会打印两行，第二行就是手机要输的地址：

```
独山麻将 · 网页对局  →  本机  http://127.0.0.1:8770
   手机/平板（连同一个 Wi-Fi）→  http://172.26.68.203:8770   [WLAN]
```

## 2. 打不开时按顺序查（99% 是地址或网段）

1. **先确认服务活着**：本机 `curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8770/`
   必须是 `200`。不是 200 → 服务没起或端口被占，先解决这个。
2. **确认当前 IP**：`ipconfig getifaddr en0`（Wi-Fi）或 `ifconfig | grep "inet "`。
   文档里的 IP 只是写文档那一刻的值，**以命令输出为准**。
3. **手机和电脑必须在同一网段**：
   - 手机用 4G/5G、电脑连 Wi-Fi → 不通；
   - 电脑连的是公司/校园网（`172.x` 段常见），手机连的是家里 Wi-Fi → 不通；
   - 访客网络、路由器「AP 隔离」也会让设备互相不可见。
4. **用 IP，不要用 `127.0.0.1`**：手机上 `127.0.0.1` 指手机自己。
5. **macOS 防火墙**：系统设置 → 网络 → 防火墙。若开启，允许 `python3.13`
   接受传入连接（或临时关闭对比一次）。
6. **公司网络的入站策略**：`172.26.x` 这类网段常由 IT 统一管控，可能禁止
   终端之间的互访。这种情况换手机热点（电脑连手机热点，再用热点网段 IP）
   最快。

## 3. 想让手机以外的人也能访问

当前**没有**公网部署：服务只在这台机器上监听局域网端口，没有端口映射、
没有反向代理、也没有云主机。要让外网访问需要额外做（二选一）：

- 内网穿透（frp / cloudflared 隧道），把 `8770` 暴露成一个 https 域名；
- 部署到有公网 IP 的服务器（需要把 `.venv`、模型和 `web/` 一起搬过去）。

## 4. 前端已做的移动端适配

| 项 | 做法 |
|---|---|
| 档位判定 | `min(宽,高) ≤ 620` 或 `宽 ≤ 900` → `html.mob` 紧凑档；桌面（>900 且 >620）逐像素不变 |
| 底部一行 | 手牌宽度由 JS 按副露数精算（`fitMyRow`），保证头像+副露+手牌**单行放下**，底边保持对齐 |
| 牌河/底盘 | `#river`、`#center-mat` 用 `--rs`（JS 按视口算）整体 `scale()`，内部 600×600 的写死坐标一处不用改 |
| 计时盘 | 单独 `--cs` 缩放，倒计时/余牌字号先放大再缩回去，屏上仍清晰 |
| 门禁 | **竖屏不放行**：触屏设备竖屏时 `#gate`（top layer `<dialog>`，`showModal()`）盖住全屏，提示「请横屏游玩」，横过来立即进入；电脑端窗口宽 < **1024px** 同样被拦，提示拉宽或 F11 全屏。门禁期间 Esc 无效、底层不可点 |
| 触屏 | 点击高亮、双击缩放、橡皮筋滚动全部禁用；按钮点按区加大 |
| 面板 | 教练/流水面板小屏默认更小；桌面保存的尺寸在小屏会收紧（`applyLogSize/applyCoachSize`） |
| 刘海屏 | `viewport-fit=cover` + `env(safe-area-inset-*)` 留边 |
| 保存的拖动位置 | 只有整块还在当前视口内才恢复，否则回退到小屏默认位（`makeDraggable`） |

## 5. 已知取舍

- **竖屏不做任何适配**（手机竖屏直接门禁拦截，转横屏即玩）。
- 电脑端最小宽度 **1024px**（实测 1024×720 布局完整可用；900 宽开始出现座位/面板重叠）。
- 副露打到 4 组时横屏单行也能放下（JS 会把手牌缩到 ~45px）。
- 手机上搜索档（深算 32 / 极算 128）单步 1.2 s / 7 s，推荐值会明显滞后；
  想要跟手的推荐就用「大师」贪心，或用离线单机版（四档全贪心）。
