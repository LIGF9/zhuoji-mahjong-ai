# 手机 / 平板访问（同一局域网）

服务端已改为默认监听 `0.0.0.0`，手机连上**同一个 Wi-Fi** 就能直接玩。

## 1. 启动

```bash
python web/dushan_server.py --port 8770 --threads 8
```

启动日志会直接打印手机要输的地址，例如：

```
独山麻将 · 网页对局  →  本机  http://127.0.0.1:8770
   手机/平板（连同一个 Wi-Fi）→
      http://192.168.31.218:8770   [WLAN]
```

手机浏览器打开那一行 `http://192.168.x.x:8770` 即可。
（`127.0.0.1` 在手机上指的是手机自己，不要用。）

> 想限制为只有本机能访问时：`--host 127.0.0.1`。

## 2. 手机打不开时（99% 是防火墙）

本机 Wi-Fi 目前被 Windows 标记为**公用网络**，且没有 8770 的放行规则 → 入站默认**拦截**。

**一键放行**：右键 `scripts/allow_firewall.cmd` → **以管理员身份运行**。
它等价于下面两条命令：

```powershell
netsh advfirewall firewall add rule name="DushanMahjong 8770 TCP" dir=in action=allow protocol=TCP localport=8770
netsh advfirewall firewall add rule name="DushanMahjong 8770 UDP" dir=in action=allow protocol=UDP localport=8770
```

> 只放行 8770 端口，不放开整个网络；删除规则：
> `netsh advfirewall firewall delete rule name="DushanMahjong 8770 TCP"`（UDP 同理）。

也可以不改防火墙，改用**「专用网络」**（更宽松但仍受规则管控）：
设置 → 网络和 Internet → WLAN → 当前网络 → 网络配置文件 = 专用。
注意这只改了网络类别，**端口规则仍需放行**。

其它排查项：
- 手机和电脑必须在**同一个 Wi-Fi/路由器**下（访客网络、5G/2.4G 隔离都不行）。
- 路由器开了「AP 隔离 / 访客网络隔离」时，设备之间互相不可见。
- 电脑上验证服务活着：`curl http://127.0.0.1:8770/api/meta`。
- 杀软的「网络防护」也可能拦入站，临时关掉对比一次。

## 3. 前端已做的移动端适配

| 项 | 做法 |
|---|---|
| 档位判定 | `min(宽,高) ≤ 620` 或 `宽 ≤ 900` → `html.mob` 紧凑档；桌面（>900 且 >620）逐像素不变 |
| 底部一行 | 手牌宽度由 JS 按副露数精算（`fitMyRow`），保证头像+副露+手牌**单行放下**，底边保持对齐 |
| 牌河/底盘 | `#river`、`#center-mat` 用 `--rs`（JS 按视口算）整体 `scale()`，内部 600×600 的写死坐标一处不用改 |
| 计时盘 | 单独 `--cs` 缩放，倒计时/余牌字号先放大再缩回去，屏上仍清晰 |
| 门禁 | **竖屏不放行**：触屏设备竖屏时 `#gate`（top layer `<dialog>`，`showModal()`）盖住全屏，提示「请横屏游玩」，横过来立即进入；电脑端窗口宽 < **1024px** 同样被拦，提示拉宽或 F11 全屏。门禁期间 Esc 无效、底层不可点 |
| 触屏 | 点击高亮、双击缩放、橡皮筋滚动全部禁用；按钮点按区加大 |
| 面板 | 教练/流水面板小屏默认更小；桌面保存的尺寸在小屏会收紧（`applyLogSize/applyCoachSize`） |
| 刘海屏 | `viewport-fit=cover` + `env(safe-area-inset-*)` 留边 |
| 保存的拖动位置 | 只有整块还在当前视口内才恢复，否则回退到小屏默认位（`makeDraggable`） |

## 4. 已知取舍

- **竖屏不做任何适配**（手机竖屏直接门禁拦截，转横屏即玩）。
- 电脑端最小宽度 **1024px**（实测 1024×720 布局完整可用；900 宽开始出现座位/面板重叠）。
  要改阈值改 `dushan.html` 里的 `DESKTOP_MIN_W` 常量和门禁文案即可。
- 副露打到 4 组时横屏单行也能放下（JS 会把手牌缩到 ~45px）。
