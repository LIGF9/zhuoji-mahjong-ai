# 仓库结构（2026-11-12 整理）

> 本文是 `LIGF9/zhuoji-mahjong-ai` 的结构总览。改动目录前请先读这一页，
> 避免把「看起来没人用」的东西当成死代码删掉（下面第 5 节有专门说明）。

## 1. 一句话定位

一个贵州独山麻将 AI，对外有**两条产品线**，共用**一套规则内核 + 一套权重**：

| 产品线 | 形态 | 入口 | 网络 |
|---|---|---|---|
| 联机网页版 | 浏览器打开 `http://<本机IP>:8770` | `web/dushan_server.py` | 局域网，Python 后端 + Rust 搜索内核 |
| 离线单机版 | Android APK（39.6 MiB） | `tauri-offline/` | 完全离线，进程内起 HTTP 服务，tract 纯 Rust 推理 |

## 3. 三条链路

**① 联机对局**
```
浏览器 → web/dushan_server.py → zhuoji/dushan.py（规则）
                              → rust_engine（dushan_engine.so，搜索 + 结算）
                              → zhuoji/forward.py（ONNX / CoreML 前向）
```

**② 离线对局**
```
WebView(dushan.html) → 127.0.0.1:8791 → offline/src/http.rs
                                      → dushan_engine::state::Game（规则）
                                      → offline/src/{ting,policy}.rs（速听 / tract 推理）
素材与权重全部 include_bytes! 进 .so，无文件 IO。
```

**③ 训练与评测**
```
gen_exit.py（教师标注，ORT 快路径） → train_exit.py（ExIt）
gen_distill.py → train_distill.py → tools/distill_slim.py（蒸馏 slim_s）
eval_pairs.py（同池同 seed 四座轮转 + 95% CI）
tools/tost_gate.py / tier_matrix.py / settle_parity.py（闸门与对拍）
```

## 4. 常用命令

```bash
# 联机版
python web/dushan_server.py --port 8770

# Rust 内核（改完 state.rs/search.rs 必须重建，产物落仓库根目录）
cd rust_engine && ./build.sh

# 结算对拍（Python vs Rust，改规则后必跑）
.venv/bin/python tools/settle_parity.py 300 8

# 离线内核强度矩阵
cd offline && ./target/release/tier_arena --seeds 1500

# 离线 APK（需要 JDK；本机在 ~/jdks/jdk-21.0.2.jdk）
cd tauri-offline && npm run android:build
```

## 5. 「看着没人用但删不得」的清单

整理时用 AST 做过一轮全仓引用分析，以下文件**没有任何显式调用方，但必须保留**：

| 文件 | 为什么不能删 |
|---|---|
| `zhuoji/rules.py` | 不是死引擎。`DushanGame` 继承它，且仍直接用它的 21 个方法：`play` `step` `legal_actions` `clone` `_draw_from_wall` `_enter_self_phase` `_settle_dou` `_settle_chicken` … 删了独山规则直接崩。 |
| `web/coach.py` | 只被 `web/dushan_server.py` 以裸 `import coach` 引用（`web/` 在 sys.path 里），简单 grep 容易漏。 |
| `dushan_engine.so` | 编译产物，但仓库定位是「clone 下来就能玩」；`.gitignore` 里没有它。 |
| `tests_quad_gold.py` | 没有 `if __name__ == "__main__"`，但顶层会 `sys.exit(0/1)`，是可执行的鸡分金标准用例。 |
| `models/champ_exit_p48.pt` | 37.7 MB，但在 `champions.json` 注册、`/api/meta` 里可选，是线上附加冠军。 |
