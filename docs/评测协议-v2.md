## 1. 冻结统计口径（一字不改）

沿用 `tools/final_eval_report.py::per_seed` / `stats`，且被 `tools/gate_decision.py`、`tools/bestof_rank.py`、`tools/pool_chunk.py` 直接 import 复用：

```
对每条 (seed, cand_seat) 记录：
    d = v[cand_seat] − mean(v[其余三家])
同一 seed 的四座旋转结果取平均  ⇒  1 个独立样本
在 seed 维度算 mean / SE / z / 双侧正态近似 p
```

- `v` 默认 = `deltas`（零和分差）。
- **禁止**：取 `deltas[0]`、不做四座平均、把 `(seed,seat)` 行当独立样本、用自对弈胜率、用 val loss 判强度、用 Q 拟合度替代强度。
- 任一片必须先校验 `deltas` 严格零和、每 seed 四座齐全、`unique(seed,cand_seat)` 无重复。

## 2. 锁死常数表（看结果前写死，禁止事后调整）

| 量 | 值 | 说明 |
|---|---|---|
| δ（最小决策效应 MDE） | `0.5` 分/副 | placement 相邻名次差 45 分 ÷ 90 副/场 ≈ 0.5 分/副 ≈ 一场差一个名次；与 E-SLIM 非劣 margin 同源 |
| TOST 等价 margin | `[−0.5, +0.5]` 分/副 | 双侧各 α=0.05 ⇔ 90% CI 完全落在区间内 |
| 非劣 margin | `−0.5` 分/副 | 单侧 α=0.05 |
| 优势 / 劣势显著性 | 双侧 α=0.05 | 95% CI 不含 0 |
| CI 算法 | 正态近似 `z=1.645 / 1.960` | 不引入 t 分布、贝叶斯、Wald 修正 |
| cluster bootstrap | `B=10000`、`default_rng(20261110)`、重采单位 = **seed** | 只作稳健性对照，不取代解析判定 |
| BH-FDR | `q=0.05`（step-up） | 多片探索性比较 |
| Holm | `α=0.05`（step-down） | 与既有 §6.71.4 并列展示，互不改写 |
| RNG / 数值容差 | 全部固定；解析口径与 `final_eval_report` 逐位一致容差 `1e-12` | 不一致即 FAIL 退出 |

## 3. 判定规则（公式写死）

设 `Δ = mean(seed 级样本)`、`SE`、`δ = 0.5`：

```
ci95 = [Δ − 1.960·SE, Δ + 1.960·SE]
ci90 = [Δ − 1.645·SE, Δ + 1.645·SE]
Φ(z) = 0.5·erfc(−z/√2)

TOST:  z1 = (Δ + δ)/SE        p1 = 1 − Φ(z1)      （H0: μ ≤ −δ）
       z2 = (δ − Δ)/SE        p2 = 1 − Φ(z2)      （H0: μ ≥ +δ）
       p_TOST = max(p1, p2)
统计等价 ⇔ p_TOST < 0.05      （⇔ ci90 ⊂ (−δ, +δ)）
非劣     ⇔ p1 < 0.05          （⇔ Δ − 1.645·SE > −δ）
```

## 4. 双维度类别与允许文案（唯一表述来源）

维度 A（方向）：`显著优势`（ci95 下界 > 0）/ `显著劣势`（ci95 上界 < 0）/ `无足够证据`。
维度 B（实际意义）：`统计等价` / `非劣但不等价` / `不可分辨`。

| A × B | 允许写法 |
|---|---|
| 显著优势 × 统计等价 | 「显著为正，但幅度小于 δ，实际意义有限」 |
| 显著优势 × 非劣但不等价 | 「显著为正，且非劣成立」 |
| 显著优势 × 不可分辨 | 「显著为正；样本不足以判定等价 / 非劣」 |
| 显著劣势 × 任意 | 「显著为负」 |
| 无足够证据 × 统计等价 | 「统计等价（在 ±0.5 内）」 |
| 无足够证据 × 非劣但不等价 | 「非劣成立；优势无足够证据」 |
| 无足够证据 × 不可分辨 | 「无足够证据」 |

**「不可分辨」≠「等价」。** 前者是证据不足，后者是在预锁 margin 内的主动判定；把两者混写是本协议要根除的主要误读。

## 5. seed 块 cluster bootstrap

- 重采单位是 **seed**（四座已折叠为一个样本），不是单局、不是 `(seed,seat)` 行。Mortal-S42 明确指出单局重采不能当作 seed 组聚类证据。
- 实现：一次生成 `(B, n)` 整数索引矩阵，`B=10000`、RNG 固定 `20261110`；报 bootstrap SE、百分位 95% CI、以及与解析 CI 的偏差。
- **bootstrap 不参与判定**：类别只由第 3 节解析公式给出。bootstrap 出现大偏差时只写「样本分布可能偏离正态，需谨慎」，不得据此改 δ、改 p 或改类别。

## 6. 多重比较与预注册

- 每个实验在开工前**预注册 1 个主比较**（m=1，不校正），其余全部标为探索性。
- 探索性多片用 **BH-FDR q=0.05**；若该片同时受既有 Holm 判据约束，两种校正并列展示，**不得互相替换或事后择优**。
- family 成员、顺序、样本量在开工前写死；禁止看结果后升格主比较、合并 family、事后加片。
- 跨实验、跨对手、跨池的 Δ **不可相减、不可合并、不可 pooled**。

## 7. ns 文案纪律

`p ≥ .05` 或落在「无足够证据」格时，**只允许**写「无足够证据 / 分辨率不足」。
**禁止**：「无差异」「打平」「并列」「一样强」「证明等价」「已到顶」「证明没有提升」。
95% CI 跨 0 时，既不排除小优势也不排除零优势，必须如实同时写出两端。

## 8. 分辨率与功效（只解释，不调参）

- 历史 `σ≈6.915` 分/副 ⇒ `SE(500)=0.309`、`SE(120)=0.631`、`SE(n)=6.915/√n`。
- `1.645·SE(500)=0.508 > δ=0.5` ⇒ 真实 Δ=0 时 500 seed 的 TOST 等价判出概率接近 0；理论需 `n≥518` 才有 `1.645·SE<0.5`（实际还需余量）。
- 对 `+0.5` 效应，500 seed 的 80% 功效不足（约 40%）；对 `+0.679` 约 59%。
- **这些是设计事实，不是调参许可**：不得在看结果后扩样、改 δ、改 margin 或改 α。

## 9. 暂不启用项与启用条件

| 项 | 当前状态 | 启用条件 |
|---|---|---|
| per-decision 诊断量（弃牌 / 响应一致率等） | **不启用**：现有 JSONL 无动作轨迹字段，不得估算或伪造 | 在 `eval_pairs.py` 增字段属改评估口径，须单独批准；且只作早期筛选，**不得替代强度判定** |
| anytime-valid / e-values / α-spending | **不启用**：本轮全部为一次性固定样本、无连续窥视 | 若要边跑边看，须在开工前预登记 e-value 阈值或 α-spending 函数 |
| TOST 用于「证明更强」 | **禁止** | TOST 只回答等价 / 非劣；优势仍由双侧 95% CI 判定 |
